## Methodology

My lab assessments follow a structured approach:

1. Define the environment, objectives, and authorized scope.
2. Perform network reconnaissance and discovery.
3. Enumerate hosts, services, users, and configurations.
4. Assess identified security weaknesses.
5. Validate observations using available evidence.
6. Document technical findings and potential business impact.
7. Provide practical remediation recommendations.

All practical testing documented in this portfolio was conducted in isolated lab environments that I built and controlled.
